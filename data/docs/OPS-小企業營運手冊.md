# 小企業／合作社｜營運手冊（公開版）

> 對象：理事長、輪值窗口、開發者、面試官  
> 原則：**官網不自建金流**；日常用 Google；進階後台用學習站示範。

---

## 1. 平常怎麼管？（小企業常見做法）

| 工作 | 建議做法 | 你們現況 |
|------|----------|----------|
| 客人預約／詢價進來 | Google 表單 → 試算表 | ✅ 已接 |
| 有人填了要通知 | 表單「新回應 Email 通知」 | 建議開啟 |
| 誰負責回覆 | 試算表加欄：負責人／狀態 | 人工在 Sheets 改 |
| 個人買東西 | 外部平台（Pinkoi）結帳 | 即將開賣 |
| 企業大宗 | 採購表 → 報價 → 匯款 → 出貨 | ✅ 表單已接 |
| 「後台系統」 | 多數小企業＝Sheets＋Line／Email | 學習站＝面試加強版 |

**為什麼官網 5500 點不到「後台」？**  
因為正式官網是**靜態檔**（Cloudflare 丟檔），本來就沒有登入後台。  
後台在學習站：`http://127.0.0.1:5001/admin`（需先 `python run.py`）。  
本機示範時，官網左下會出現「選物」快捷，頁尾有「本機工作站」連結（僅 localhost）。

## 2. 兩條線（不要混）

```
【營運線｜給合作社真的用】
  官網表單 → Google Sheets → Email 通知 → 電話／匯款確認 → 出貨／接待

【學習線｜給面試官看你會維運】
  同一筆預約可雙寫 → Flask DB → /admin 改狀態（新進→已聯繫→已確認付款→結案）
```

面試講法：我維持客戶低成本營運，另做可跑的狀態後台證明職能。

## 4. 「購買／結清／出貨」做到哪就好？

| 等級 | 內容 | 做不做 |
|------|------|--------|
| A 基本（建議停這） | 意向／詢價進表或 DB → 後台改：已聯繫／已匯款／結案 | ✅ 學習站已有 |
| B 平台購買 | Pinkoi 結帳、平台訂單為準 | 開館後 |
| C 站內購物車＋金流 | 綠界／Stripe | ❌ 不做（停損） |

你要的「點了有紀錄 → 後端確認匯款出貨」＝**等級 A**，不是 C。  
商品卡 →「企業採購」或「商品意向」→ 後台狀態機即可。

---

## 5. 帳密與安全（學習站）

- 後台：`.env` 的 `ADMIN_USERNAME`／`ADMIN_PASSWORD`（預設 admin／1234 僅本機）  
- 勿把 `.env`、`pages/專案狀態/` 上傳 GitHub  
- 正式站不要公開掛「後台」連結給全世界
