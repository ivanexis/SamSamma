## 1. 為什麼 5500 官網沒有後台按鈕？

| 站 | 網址 | 有沒有後台 |
|----|------|------------|
| 官網（靜態） | `http://127.0.0.1:5500/.../index.html` | ❌ 設計上沒有 |
| 學習站 | `http://127.0.0.1:5001/admin` | ✅ 要先開 run.py |

小企業管理＝**Sheets＋通知**；學習站後台＝**徵才加分展示**。  
本機官網頁尾會加「工作站」入口（僅 localhost 顯示）。

## 3. 「我要一點基本購買功能」＝建議做成這樣

```
使用者點商品
  → B2C：即將開賣／未來連 Pinkoi（平台訂單）
  → B2B／意向：procurement 或學習站「商品意向」
       → 資料進 Sheets 或 DB
       → 人員在後台把狀態改成「已確認付款」→「結案」＝匯款＋出貨確認
```

這就是小企業「訂單管理」的最小閉環，**不需要結帳頁**。
